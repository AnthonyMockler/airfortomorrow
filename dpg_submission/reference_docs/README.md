# DPG Reference Docs And Examples

This folder collects public reference links and example DPG profiles found during DPG submission research for Air for Tomorrow.

These files are not final submission answers. They are working references for future agents to inspect before drafting final questionnaire text, evidence links, or implementation tasks.

## Files

- `similar_dpg_examples.md` - Comparable DPG registry examples, especially climate, geospatial, health, and AI/model projects.
- `official_dpga_references.md` - DPGA standard, questionnaire, submission, review, and toolkit links.
- `responsible_ai_references.md` - UN Global Pulse and UNICEF AI guidance links for risks/harms/benefits review.
- `partner_reference_sources.md` - Public sources for Lao PDR ministry/NRERI naming and partner context.
