# Responsible AI References

Last checked: 2026-04-28

Use these references when completing the responsible-AI risks/harms/benefits follow-up. The default evidence artifact should remain `MODELCARD.MD`; improve the model card if these references reveal gaps.

| Resource | URL | Notes |
|---|---|---|
| UN Global Pulse Risks, Harms and Benefits Assessment Tool | https://www.unglobalpulse.org/wp-content/uploads/2023/12/UN-Global-Pulse_PrivacyAssessmentTool_2020.pdf | Structured privacy/ethics/data-protection review for data innovation projects. |
| UNICEF Guidance on AI and children | https://www.unicef.org/innocenti/reports/policy-guidance-ai-children | UNICEF child-centred AI guidance. Check whether Air for Tomorrow should map model-card guidance to its requirements. |
| UNICEF AI for Children project | https://www.unicef.org/innocenti/projects/ai-for-children | UNICEF project page on AI and child rights. |
| UNICEF Digital Impact: Artificial intelligence for children | https://www.unicef.org/digitalimpact/what-we-do/artificial-intelligence-children | Public UNICEF overview of responsible AI for children and young people. |
| DPGA blog: AI systems as DPGs / AI governance context | https://www.digitalpublicgoods.net/blog/ | Use search within the blog for current AI-system DPG guidance and privacy/security framework updates. |

## Follow-Up Use

1. Read `MODELCARD.MD` first.
2. Complete or adapt the UN Global Pulse assessment if it fits the DPG submission need.
3. Check whether UNICEF AI guidance has a required internal or public template.
4. If Air for Tomorrow is missing child-rights, oversight, limitation, or misuse language, improve `MODELCARD.MD`.
