# DPG Submission Workspace

This folder contains the working evidence pack and draft questionnaire answers for submitting Air for Tomorrow to the Digital Public Goods Alliance.

Current status: working/internal-prep folder. Do not treat these drafts as final public repository documentation. Decide later whether to promote selected polished outputs into public repo docs after final review/submission.

## Contents

- `TODO.md` - Consolidated checklist of remaining work before DPG submission.
- `official_resources.md` - DPGA source links used to prepare the evidence pack.
- `questionnaire_draft.md` - Draft answers mapped to the DPG application questionnaire.
- `evidence_matrix.md` - Criteria-by-criteria evidence, gaps, and proposed work.
- `open_ai_model_evidence_map.md` - Open AI Model evidence map, current citations, and AI-specific submission gaps.
- `impact_evidence_followup.md` - Follow-up checklist for deployment, usage, outcome, and technical impact evidence.
- `partner_citations.md` - Public partner-name and NRERI/MAE citation notes.
- `standards_best_practices_research.md` - Follow-up research notes for DPG Indicator 8.
- `responsible_ai_assessment_followup.md` - Follow-up note for UN Global Pulse / UNICEF AI risks, harms, and benefits assessment.
- `reference_docs/` - Public reference links and comparable DPG examples found during web research.

## Working Rule

Treat these files as submission drafts. Public links should be checked again immediately before final submission because the application content becomes public, while applicant contact details remain private under DPGA review policy.

Do not include sensitive internal review notes, unapproved partner wording, or provisional contact details in public-facing docs without final approval.
